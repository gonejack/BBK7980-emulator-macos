# BBK7980 模拟器 v0.6.0

首个公开预览版。下载 Windows x64 ZIP，解压后运行 `BBK7980.exe`。首次启动选择[步步高官网 7980 V1.10 升级包](https://down.eebbk.net/xzzx/7980/1/7980sj.exe)，模拟器会在本地生成运行镜像。启动后在「娱乐」中打开随包提供的《扫雷》。

- 65C02 系统模拟、240 × 120 四级灰度显示和按真机照片排列的面板。
- 校正方向键映射，支持电脑键盘和鼠标点击面板。
- 导入时由原厂固件格式化虚拟 NAND，经模拟串口写入并逐项读回。公开 ZIP 提供 GPL 源码、扫雷和 Unifont 源字形。
- PSG 方波旋律输出可用。原机语音及中文输入仍有兼容性限制。

固件、原厂软件和运行镜像由用户在本地导入生成。下载的 ZIP 可按 `SHA256SUMS.txt` 校验。
