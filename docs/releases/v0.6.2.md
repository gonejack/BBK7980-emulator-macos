# BBK7980 模拟器 v0.6.2

## 下载

- [BBK7980 模拟器（Windows x64）](https://github.com/HelloClyde/BBK7980-emulator/releases/download/v0.6.2/BBK7980-emulator-0.6.2-win64.zip)
- [V1.10 系统镜像](https://github.com/HelloClyde/BBK7980-emulator/releases/download/v0.6.2/BBK7980-V1.10-runtime.zip)包含完整固件和预装 NAND。

将系统镜像包内的 `runtime` 文件夹解压到 `BBK7980.exe` 同级，再启动模拟器。也可以在首次启动时选择[官网 V1.10 升级包](https://down.eebbk.net/xzzx/7980/1/7980sj.exe)来生成镜像。

镜像中的原厂组件经授权分发，相关权利归原权利人。模拟器和镜像各有独立的 SHA-256 校验文件。

## 文件传输

- 「导入文件」打开电脑文件选择器，可一次选择多个普通文件或 SDK 应用包。
- 「导出文件」显示当前 NAND 的文件名和大小。点击选中一个或多个文件，再选择电脑上的保存目录。
- 批量导入完成后统一保存，任何文件校验失败都会恢复这一批操作前的 NAND。实际传输会重启模拟器，请先保存应用进度。

已有模拟器可将原来的 `runtime/` 复制到新版目录，以便继续使用自己的镜像和存档。
