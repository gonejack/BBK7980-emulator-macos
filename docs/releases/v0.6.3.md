# BBK7980 模拟器 v0.6.3

外置 SRAM 设为 **128 KiB**。V1.10 固件跟踪显示，原厂《日程》的四个程序分页与堆块合计占用至少 69,384 字节外置 RAM。系统启动、游戏和文件传输已在 128 KiB 配置下验证。

- [BBK7980 模拟器（Windows x64）](https://github.com/HelloClyde/BBK7980-emulator/releases/download/v0.6.3/BBK7980-emulator-0.6.3-win64.zip)
- [V1.10 系统镜像](https://github.com/HelloClyde/BBK7980-emulator/releases/download/v0.6.3/BBK7980-V1.10-runtime.zip)

解压模拟器，将镜像包中的 `runtime` 放在 `BBK7980.exe` 同级，然后启动。已有用户可复制原来的 `runtime` 使用镜像和存档。
